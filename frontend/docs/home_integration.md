# 홈 일정과 D-day

홈 중앙에는 일정 카드와 `내가 할 일`을 표시합니다. 기존 화면의 하늘색
그라데이션, 둥근 프레임, 공용 로고 캐릭터와 Fredoka 숫자 스타일을 사용합니다.
이번 주 일정 목록은 추가하지 않았습니다. 작은 화면에서는 여백과 카드 크기를
줄이고 중앙 콘텐츠만 스크롤하며, 프로필과 하단 캘린더·방 버튼은 유지합니다.

## 일정 카드와 D-day

- 기본값은 아직 끝나지 않은 일정 중 가장 가까운 일정입니다. 개인 일정과
  날짜가 있는 약속방 일정을 같은 `CalendarController`에서 읽습니다.
- 카드의 `D-day 설정`에서 일정 검색·선택을 하면 원하는 일정 하나를 홈에
  고정합니다. `변경`에서 다른 일정 선택 또는 `설정 해제`가 가능합니다.
- 일정이 없으면 캐릭터와 약속 만들기 버튼을 표시합니다. D-day 선택창의
  `새 일정 추가`로 개인 일정을 바로 만든 뒤 선택할 수도 있습니다.
- 개인 일정 카드는 해당 날짜의 캘린더로, 방 일정 카드는 방 상세로 이동합니다.
- D-day는 시간 차이가 아닌 현지 날짜 차이로 계산합니다. 당일은 `D-DAY`,
  이전 날짜는 `D+N`입니다. 반복 일정은 진행 중이거나 다음에 시작하는 회차를
  기준으로 표시하며, 월말 누락 날짜와 윤년을 건너뜁니다.
- 일정 수정·분류 색상 변경과 방 날짜 변경을 즉시 반영합니다. 고정한 일정이
  삭제되거나 방 일정이 해제되면 고정을 풀고 가장 가까운 일정으로 돌아갑니다.
- 홈의 날짜·가까운 일정은 분 단위와 앱 복귀 시 갱신합니다.

## 내가 할 일

확정 전인 오늘 이후의 방 및 날짜 미정인 방 중 다음 항목을 보여줍니다.

- 현재 참여자 `나`가 취향을 제출하지 않음 → 방 상세의 취향 입력으로 이동
- 모두 제출했고 추천 코스가 있음 → 추천 코스 화면으로 이동

과거 날짜의 방과 확정한 방은 제외합니다. 취향 저장 또는 약속 확정 후에는
컨트롤러 알림을 통해 할 일이 즉시 갱신됩니다. 할 일이 없으면 빈 상태 카드를
표시합니다. 서버 알림이나 코스 자동 생성 기능을 추가하지 않았습니다.

## 상태와 검증

D-day 선택은 일정·방과 같이 현재 로그인 세션의 메모리에 보관됩니다.
화면을 이동해도 유지되며 로그아웃·앱 재시작 시 초기화됩니다.

`test/home_dashboard_test.dart`에서 D-day 날짜 계산, 일정 수정·삭제와 방 날짜
해제, 반복 일정의 다음 회차, 윤년 경계, 320px 화면과 검색 키보드, 선택·변경·해제,
화면 연결, 할 일 완료 반영과 빈 선택창의 새 일정 추가를 검증합니다.
