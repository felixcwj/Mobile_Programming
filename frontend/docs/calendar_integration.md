# 캘린더

로그인 후 홈 왼쪽 아래 파란색 원형 캘린더 버튼에서 월간 달력을 엽니다.
참고 이미지의 흰 배경, 큰 월 숫자, 선택한 날짜의 검은 배경,
날짜별 색상 막대와 하단 이벤트 추가 버튼을 반영했습니다.

## 개인 일정

- 날짜 선택 및 길게 눌러 추가, 이전·다음 달 이동과 좌우 스와이프
- 오늘로 이동, 날짜 선택 이동, 제목·위치·메모 검색, 월간 일정 목록
- 선택 날짜 일정 목록에서 편집, 일정 메뉴에서 삭제
- 제목, 시작·종료 날짜와 시간, 하루종일, 개인·대학·업무 분류, 위치와 메모
- 매일·매주·매월·매년 반복. 반복 일정을 편집·삭제하면 전체 반복에 적용
- 월요일 시작 및 주말 색상 표시 설정

종료 시각은 해당 시각을 포함하지 않습니다. 하루종일 일정은 편집 화면에서
선택한 종료 날짜까지 표시하며 내부에서는 다음 날 0시를 종료 경계로 저장합니다.
매월 31일 일정은 31일이 없는 달에는 표시하지 않고, 2월 29일의 매년 반복은
윤년에만 표시합니다. 여러 날에 걸친 일정은 포함된 각 날짜에 표시합니다.

## 약속방 일정

`HomeScreen`은 `RoomsController`와 `CalendarController`를 한 번 생성하여
여러 화면에서 공유합니다. 방 상세의 `약속 날짜 정하기`에서 날짜와 시간을
정하면 해당 날짜에 방 일정이 자동으로 표시됩니다. 코스 상태와 관계없이
날짜가 정해진 방을 표시하며, 날짜 미정인 방은 달력에 넣지 않습니다.

방 날짜 변경·일정 해제는 달력에 즉시 반영됩니다. 방 ID로 일정을 파생하므로
코스를 확정하거나 달력을 다시 열어도 같은 일정이 중복 생성되지 않습니다.
방은 현재 시작 시간만 갖고 있어 달력에서도 시작 시간만 표시합니다.
달력에서 약속방 일정을 누르면 방 상세로 이동하여 날짜를 수정합니다.

## 저장 범위

새 패키지나 외부 캘린더 권한을 추가하지 않았습니다. 일정은 현재 로그인 세션의
메모리에 보관되며 화면을 나갔다 들어와도 유지됩니다. 로그아웃하거나 앱을
재시작하면 초기화됩니다. 서버·기기 캘린더 동기화 및 영구 저장은 후속 연동 대상입니다.
알림 시간은 일정 메타데이터로 저장하며 실제 기기 알림 발송은 아직 지원하지 않습니다.

## 검증

`test/calendar_test.dart`에서 여러 날 일정의 종료 경계, 반복 날짜 계산,
약속방 날짜 변경·해제 및 중복 방지, 연도·월 이동, 검색, 작은 화면과 키보드,
개인 일정 저장·편집·삭제와 화면 간 상태 유지를 검증합니다.
