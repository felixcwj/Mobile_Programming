# 캘린더

로그인 후 홈 왼쪽 아래 캘린더 버튼에서 월간 달력을 엽니다.
홈·약속방과 같은 하늘색 배경, 둥근 프레임과 파란색 강조색을 사용합니다.
상단은 `Plan it`과 공용 로고 캐릭터이며, 바로 아래 연·월을 눌러 날짜를
이동합니다. 선택 날짜, 오늘 표시, 일정 카드와 추가·저장 버튼도 공용 테마에
맞췄습니다. 기존 디자인 `ver1`은 `docs/design_versions/calendar/ver1.zip`에
보관되어 있습니다.

## 개인 일정

- 날짜 선택 및 길게 눌러 추가, 이전·다음 달 이동과 좌우 스와이프
- 오늘로 이동, 날짜 선택 이동, 제목·위치·메모 검색, 월간 일정 목록
- 선택 날짜 일정 목록에서 편집, 일정 메뉴에서 삭제
- 제목, 시작·종료 날짜와 시간, 하루종일, 개인·대학·업무 분류, 위치와 메모
- 매일·매주·매월·매년 반복. 반복 일정을 편집·삭제하면 전체 반복에 적용
- 월요일 시작 및 주말 색상 표시 설정
- 달력 설정 → 분류별 색상에서 개인·업무·대학 색상 선택. 날짜별 막대,
  일정 카드, 검색 결과와 편집 화면의 분류 표시에 즉시 적용

시·분은 공용 스크롤 선택기로 00:00~24:00 범위에서 1분 단위로 선택합니다.
새 이벤트의 시작 날짜는 달력에서 선택한 날짜입니다. 시작을 누르면 날짜를
다시 고르지 않고 시간 스크롤이 바로 열립니다. 종료는 날짜를 고른 뒤 시간을
선택하므로 이틀 이상 이어지는 일정도 등록할 수 있습니다. 하루종일 일정은
시작 날짜를 그대로 사용하고 종료 날짜만 선택합니다.
24시는 00분만 선택할 수 있고 저장 시 선택 날짜의 다음 날 00:00으로 변환합니다.
캘린더 개인 일정의 종료 시각이 자정이면 전날의 24:00으로 표시하며,
다시 편집해도 같은 날짜와 경계를 유지합니다. 새 방 생성·방 날짜 변경에도
같은 시간 선택기를 사용합니다.

종료 시각은 해당 시각을 포함하지 않습니다. 하루종일 일정은 편집 화면에서
선택한 종료 날짜까지 표시하며 내부에서는 다음 날 0시를 종료 경계로 저장합니다.
매월 31일 일정은 31일이 없는 달에는 표시하지 않고, 2월 29일의 매년 반복은
윤년에만 표시합니다. 여러 날에 걸친 일정은 포함된 각 날짜에 표시합니다.

## 약속방 일정

`HomeScreen`은 `RoomsController`와 `CalendarController`를 한 번 생성하여
여러 화면에서 공유합니다. 새 방의 `날짜 및 시간`에서 일정을 선택하면
방 생성 즉시 해당 날짜와 시간에 방 일정이 표시됩니다. 생성 시 개인·업무·대학 중
분류를 고르며 기본값은 개인입니다. 분류는 방 모델에 보관되고 날짜 변경이나
취향 수정·확정 시에도 유지됩니다. 달력에서도 선택한 분류와 그 색상을 사용합니다. 날짜와 시간은 필수이며,
방 이름을 비워 두면 `새 약속방`으로 생성합니다. 방 상세의 `약속 날짜 변경`에서
일정을 수정할 수 있습니다. 코스 상태와 관계없이
날짜가 정해진 방을 표시하며, 날짜 미정인 방은 달력에 넣지 않습니다.

방 날짜 변경·일정 해제는 달력에 즉시 반영됩니다. 방 ID로 일정을 파생하므로
코스를 확정하거나 달력을 다시 열어도 같은 일정이 중복 생성되지 않습니다.
방은 현재 시작 시간만 갖고 있어 달력에서도 시작 시간만 표시합니다.
달력에서 약속방 일정을 누르면 방 상세로 이동하여 날짜를 수정합니다.

## 저장 범위

새 패키지나 외부 캘린더 권한을 추가하지 않았습니다. 일정과 분류별 색상은 현재 로그인 세션의
메모리에 보관되며 화면을 나갔다 들어와도 유지됩니다. 로그아웃하거나 앱을
재시작하면 초기화됩니다. 서버·기기 캘린더 동기화 및 영구 저장은 후속 연동 대상입니다.
알림 시간은 일정 메타데이터로 저장하며 실제 기기 알림 발송은 아직 지원하지 않습니다.

## 검증

`test/calendar_test.dart`에서 여러 날 일정의 종료 경계, 반복 날짜 계산,
약속방 날짜 변경·해제 및 중복 방지, 연도·월 이동, 검색, 작은 화면과 키보드,
개인 일정 저장·편집·삭제와 화면 간 상태 유지를 검증합니다.

`test/calendar_customization_test.dart`는 시간 스크롤, 취소, 연말 24:00 변환,
자정 종료 일정 재편집·종료 경계와 분류별 색상 반영·화면 재진입을 검증합니다.
