# 나의 정보 화면 연결

`ProfileScreen`에서 두 개의 독립된 수정 화면으로 이동합니다.

- `EditProfileScreen`: 프로필 사진, 닉네임, 내 집 주소 및 계정 수정 메뉴
- `EditPreferencesScreen`: 성별, 생년월일, MBTI, 실내외 활동 선호, 음주 선호도(1~5), 거주 동네, 차량 보유 여부

기본 성향은 모두 선택 사항이며, 선택된 항목을 다시 누르면 해제할 수 있습니다.
생년월일은 `YYYY-MM-DD` 형식으로 1900년부터 오늘 사이의 유효한 날짜만 저장합니다.
만 나이는 생년월일로 계산하며 별도 저장하지 않습니다.
정확한 집 주소와 대략적인 거주 동네는 다른 필드입니다.
약속별 지역·예산·활동은 사용자 기본 성향에서 제거했으며 이후 내 방에서 입력합니다.

## 저장소와 미리보기

```dart
final profileRepository = MemoryProfileRepository(
  initialProfile: UserProfile(
    userId: 'preview-user',
    nickname: '플래너',
    email: 'planner@example.com',
    loginId: 'planit_demo',
  ),
);

ProfileScreen(repository: profileRepository)
```

같은 저장소 인스턴스를 재사용하세요. 저장은 메모리에만 유지되며 앱을 재시작하면
초기화됩니다. 앱은 기존 로그인 화면으로 시작하며, 로그인 입력을 마치면
`HomeScreen` 오른쪽 위 프로필 버튼에서 이 화면을 엽니다.
홈 화면이 로그인 시 입력한 아이디로 로컬 저장소를 한 번 생성하고 재사용하므로,
프로필을 닫았다 열어도 수정 내용이 유지됩니다. 이메일은 서버 연동 전까지 비워둡니다.
실제 인증은 아직 없으며, 로그아웃하면 화면 기록과 이 세션의 프로필·방 상태를
제거하고 로그인 화면으로 돌아갑니다. 다시 로그인하면 새 로컬 세션이 시작됩니다.

각 수정 화면은 저장 직전에 최신 프로필을 불러와 자기 영역만 갱신합니다.
뒤로 가면 작성 중인 내용이 폐기됩니다. 로딩 재시도와 저장 실패 안내를 제공합니다.
백엔드 연동 시 인증된 사용자별 `ProfileRepository.load/save`를 구현하세요.

## 사진

`image_picker`로 기기 사진을 선택하고 이미지가 열리는지 검증합니다.
선택 결과가 5MB를 넘으면 저장하지 않습니다. 사진은 프로필 모델의 읽기 전용
바이트로 보관하며 프로필 저장 시 반영됩니다. 사진 선택 취소는 기존 사진을 유지하고,
사진 삭제 후 저장하면 기본 아바타로 돌아갑니다. 서버 업로드는 아직 없습니다.
iOS 사진 접근 안내와 macOS 사용자 선택 파일 읽기 권한을 추가했습니다.

## 계정 수정

아이디는 프로필의 안정적인 `userId`와 별개인 `loginId` 필드입니다.
`AccountEditScreen`에는 현재 비밀번호와 새 아이디 또는 새 비밀번호·확인 입력창이 있습니다.
현재 프로필 화면에서는 인증 미연동 안내와 함께 변경 버튼을 비활성화합니다.
실제 계정 변경은 아직 동작하지 않으며 비밀번호를 프로필 저장소에 저장하지 않습니다.

인증 담당자가 재인증·아이디 중복 확인·변경 API를 구현한 뒤
`AccountEditScreen.onSubmit(currentPassword, newValue)`를 연결해야 합니다.
아이디 변경 성공 시에는 서버 프로필과 저장소를 다시 조회하는 흐름도 연결하세요.
클라이언트 입력 검증과 별도로 서버 정책 검증이 필요합니다.
`ProfileScreen.onLogout`은 기존 로그인 담당자의 로그아웃·화면 이동 함수를 받습니다.

## 약속 내역과 고객센터

`ProfileScreen`의 약속 내역 메뉴는 `AppointmentHistoryScreen`으로 이동하며,
현재는 요청대로 `아직 약속 없음`만 표시합니다. 내 방의 데모 약속을 가져오지 않습니다.
추후 실제 약속 목록을 연결할 예정입니다.

고객센터는 `SupportScreen`에서 문의 제목(최대 100자)과 내용(최대 2,000자)을
입력합니다. 메일 앱으로 넘기는 `mailto:` 링크에 수신처·제목·본문을 인코딩합니다.
앱에서 자동 전송하지 않으며 사용자가 메일 앱에서 전송을 완료해야 합니다.
메일 앱이 없거나 열기에 실패하면 문의 내용을 복사해 직접 보낼 수 있습니다.

기본 수신 이메일은 사용자가 지정한 `miinkoo0044@gmail.com`입니다.
`lib/config/support_config.dart`에서 관리하며, 다른 환경에서는
`--dart-define=SUPPORT_EMAIL=다른수신주소` 또는 `ProfileScreen.supportEmail`로 변경할 수 있습니다.
빈 주소를 전달하면 전송 버튼은 비활성화되며 문의 작성·복사는 가능합니다.
웹에서는 운영체제 또는 브라우저에 기본 메일 처리 앱이 설정되어 있어야 합니다.
