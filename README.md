# AI Appointment Planner

모바일 프로그래밍 팀 프로젝트

## 프로젝트 소개

여러 명이 약속을 잡을 때 발생하는 시간 및 장소 조율의 번거로움을 줄이기 위한 AI 기반 약속 플래너 앱입니다.

참여자들이 가능한 시간, 선호 지역, 예산, 활동 등을 입력하면 AI가 조건을 종합하여 약속 일정을 추천하는 서비스를 목표로 합니다.

## 주요 기능

- 약속 생성 및 참여자 관리
- 참여자별 가능한 시간 및 선호 조건 입력
- AI 기반 약속 장소 및 일정 추천
- 조건 변경에 따른 일정 재추천

## 개발 환경

- Flutter
- Dart

## 현재 구현 내용

- 홈 화면
- 약속 생성 화면
- 조건 입력 화면
- 약속 상세 화면
- AI 일정 추천 화면
- 일정 수정 화면

현재는 기본 화면 레이아웃을 구현한 단계이며, AI Agent 및 외부 API 연동은 추후 개발할 예정입니다.

## 실행 방법

Flutter 개발 환경에서 다음 명령어를 실행합니다.

```bash
cd ai_meet_planner
flutter create .
flutter pub get
flutter run
```
